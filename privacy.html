Privacy.

This site is a static page. It has no accounts, no comment forms, no advertising, and no analytics. Here is what does happen when you visit.

Last updated: November 22, 2026

What this site does not collect

There is no sign up, no newsletter, and no contact form. This site does not set cookies and does not use advertising or analytics trackers. Nothing you type is sent to makitdev, because there is nothing to type.

Data read from GitHub

The home page and contributors page request public organization data from the GitHub API. Those requests go from your browser to GitHub, so GitHub can see your IP address and request headers under its own privacy policy. makitdev does not receive a copy of that request.

Repository and contributor responses are cached in your browser's session storage for 15 minutes so the page does not repeat the same requests. The cache is cleared when the tab or browser session ends. It stays in your browser and is not sent anywhere.

Hosting logs

The site is hosted on Vercel. Like most hosting providers, Vercel may process standard request data such as your IP address, user agent, and the page requested in order to serve the site and keep it secure. That processing is governed by Vercel's privacy policy.

Links to other sites

Pages here link to GitHub. Once you follow a link, the destination site has its own privacy policy and its own data practices. Review it there.

Your choices

You can block the GitHub API requests with a content blocker. The page will still load, and it will link you to the organization page on GitHub instead of showing live repository data. You can also clear session storage at any time from your browser settings.

Questions

Privacy questions can be raised in the organization's public discussions. Do not include personal or sensitive information in a public post.
