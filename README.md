# makitdev

**Build. Share. Improve.**

The official website for [makitdev](https://github.com/makitdev), an open-source
organization building useful software, developer tools, security utilities,
applications, and experiments in public.

## Overview

This repository contains two things:

1. **A static landing page** — zero-dependency HTML, CSS, and a few lines of
   vanilla JavaScript. Open `index.html` in any browser.
2. **A WordPress theme** (`makitdev-theme/`) — the same design, packaged as a
   theme so it can be deployed on WordPress later. The homepage is controlled
   by `front-page.php`.

## Preview

Open `index.html` locally, or serve the directory:

```bash
python3 -m http.server 8080
```

Then visit <http://localhost:8080>.

## WordPress theme

The theme lives in `makitdev-theme/`. To use it:

1. Copy `makitdev-theme/` into `wp-content/themes/`.
2. Activate the theme from **Appearance → Themes**.
3. Set a static front page (or upload this theme with the WordPress
   theme/zip import) — `front-page.php` controls the homepage.

All copy is edited in `makitdev-theme/front-page.php`.

## Editing copy

All landing-page copy lives in one of two places:

- Static: `index.html`
- WordPress: `makitdev-theme/front-page.php`

Design tokens (colors, type scale, spacing) live at the top of
`assets/css/main.css`.

## Contributors page

The contributors page exists in two places, mirroring the landing page:

- Static: `contributors.html`
- WordPress: `makitdev-theme/page-contributors.php`

Both versions list the real contributors from the
[makitdev organization](https://github.com/makitdev):

- Static: `assets/data/contributors.js` — loaded as a plain script, so the
  page also works when opened directly from disk (no server, no fetch).
- WordPress: `makitdev-theme/assets/data/contributors.json` — read
  server-side by `page-contributors.php`.

Keep the two data files in sync when you change the contributor list.

To refresh the data from GitHub:

```bash
curl -s "https://api.github.com/repos/makitdev/makitdev/contributors?per_page=100"
```

## SEO & performance

Target domain: `https://makitdev.wordpress.com/` (used for canonical URLs,
Open Graph/Twitter cards, and the sitemap).

- **`robots.txt`** allows all crawlers and points to `sitemap.xml`.
- **`sitemap.xml`** lists the two public URLs.
- **Structured data**: every page ships `application/ld+json`
  (`Organization` + `WebSite` on the homepage, `WebPage` on the contributors
  page).
- **Social cards**: Open Graph and Twitter card meta reference
  `assets/images/og-1200x630.png`, generated by
  `python3 scripts/gen-og-image.py` (standard library only).
- **Minified CSS**: pages load the `.min.css` artifacts. Regenerate after
  editing a stylesheet with `node scripts/minify.js` (standard library only);
  edit the readable source, never the minified files.

Deployment/server notes (not fixable in the static files): enable gzip/Brotli
for HTML/CSS/JS, and add security headers (CSP, HSTS, `X-Frame-Options`,
`Cross-Origin-Opener-Policy`) at the host.

## Design principles

- Minimal, editorial, typography-led
- Colors: dark background, near-white text, one blue accent
- No animation library, no external trackers, no heavy images
- Respects `prefers-reduced-motion`
- Keyboard accessible, semantic HTML, visible focus states
