## What is makitdev?

makitdev is an open-source organization focused on building small, practical, and maintainable software.

We create tools that are meant to be used, not just showcased — from security utilities and developer tooling to web infrastructure and useful command-line applications.

Our goal is simple:

> Build software that solves a problem, keep it open, and make it useful to others.

## What We Build

Our projects generally fall into a few areas:

**🛠 Developer Tools**
CLI applications, libraries, APIs, utilities, and tools that make development simpler.

**🔐 Security**
Open-source security utilities for analysis, testing, automation, and defensive engineering.

**🌐 Web Infrastructure**
Small tools and components that help developers build, analyze, and maintain web applications.

**🧪 Experiments**
Technical experiments, prototypes, and ideas that may eventually become useful open-source projects.

## Our Philosophy

**Ship small. Ship often.**
A useful `v0.1` is better than an unfinished perfect idea.

**Solve one problem well.**
Projects should be useful on their own without unnecessary dependencies on an entire ecosystem.

**Open by default.**
Source code, documentation, issues, and discussions should be accessible whenever possible.

**Keep it maintainable.**
Readable code, tests, documentation, and sensible architecture matter more than unnecessary complexity.

## Project Standards

We aim for every serious project to have:

```
✓ Clear README
✓ Installation & usage instructions
✓ Tests
✓ Continuous Integration
✓ Open-source license
✓ Documentation
✓ Contribution guidelines
✓ Security policy
```

Not every experiment will start with everything above, but projects that become actively maintained should grow toward these standards.

## Open Source

Everything we build doesn't have to become a huge project. Some projects may be:

```
small CLI
    ↓
useful library
    ↓
security utility
    ↓
web tool
    ↓
experimental project
```

The common requirement is simple: **it should be useful to someone.**

## Get Involved

You don't need to be a core maintainer to contribute. You can:

- ⭐ Star projects you find useful
- 🐛 Report bugs
- 💡 Suggest improvements
- 📝 Improve documentation
- 🧪 Add tests
- 🔧 Fix issues
- 🤝 Submit pull requests

Before contributing, check the repository's `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md`.
