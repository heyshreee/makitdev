### 💡 What is makitdev?

**makitdev** is an independent open-source organization shipping small, practical, and maintainable software. 

We build tools designed to be used, read, and modified — spanning developer utilities, defensive security tooling, local-first applications, and web infrastructure.

> **Our goal:** Build software that solves a real problem, keep it open, and make it genuinely useful to others.

---

### 🧱 What We Build

Our work centers around four key focus areas:

| Area | Focus | What We Ship |
| :--- | :--- | :--- |
| **🛠️ Developer Tools** | Efficiency & developer workflow | CLIs, local utilities, automation scripts, and workflow helpers |
| **🔐 Security** | Defensive engineering & awareness | Analysis utilities, header scanners, integrity monitors, and training tools |
| **🌐 Web Infrastructure** | Modular web architecture | Vanilla components, performant site templates, and developer directories |
| **🧪 Experiments** | Prototypes & exploratory concepts | AI search engines, local-first vaults, and creative interface experiments |

### 🚀 Featured Projects

Here are some of the active projects being built under `makitdev`:

- **[chatvault-ai](https://github.com/makitdev/chatvault-ai)**  
  *A local-first ChatGPT conversation vault.*  
  Imports public shared chat links, preserves conversations in SQLite as the source of truth, exports to PDF/DOCX, and runs local semantic search powered by Ollama embeddings and ChromaDB.  
  `Python` • `SQLite` • `Ollama` • `ChromaDB`

- **[DevTab](https://github.com/makitdev/DevTab)**  
  *A terminal-style new tab extension for developers and security learners.*  
  Manifest V3, 100% local, zero tracking, zero external dependencies. Features developer shortcuts, security cheat sheets, and quick tooling.  
  `JavaScript` • `HTML/CSS` • `Manifest V3`

- **[steam-portfolio](https://github.com/makitdev/steam-portfolio)**  
  *A Steam-inspired developer portfolio template.*  
  Designed for creators, software engineers, and gamers looking for a distinct visual presentation for their personal brand and repositories.  
  `TypeScript` • `React` • `Tailwind CSS`

- **[makitdev-site](https://github.com/makitdev/makitdev)**  
  *The official organization site and contributors directory.*  
  Ultra-fast, zero-framework, accessible website with live GitHub API integration, dynamic contributor roster, and custom WordPress theme pairing.  
  `HTML5` • `CSS3` • `Vanilla JS` • `PHP`

### ⚙️ Our Engineering Philosophy

We abide by four simple principles across all repositories:

1. **Ship small, ship often.** A usable `v0.1` that solves a pain point today beats an unfinished masterpiece tomorrow.
2. **Solve one problem well.** Tools should do their primary job reliably without forcing heavy runtime or ecosystem lock-in.
3. **Open by default.** Code, issues, discussions, and roadmaps belong in the public eye.
4. **Local-first & privacy conscious.** Where possible, tools operate locally without unnecessary telemetry or cloud dependencies.

### 🤝 Contributing & Community

Open source works best when everyone can contribute. Whether you are fixing a typo, opening an issue, or building a feature, you are welcome here.

- **Check open issues**: Browse [Organization Issues](https://github.com/issues?q=is%3Aopen+is%3Aissue+user%3Amakitdev) for tasks marked `good first issue` or `help wanted`.
- **Read our standards**: Review our [Contributing Guidelines](https://github.com/makitdev/makitdev/blob/main/CONTRIBUTING.md) before submitting pull requests.
- **Report vulnerabilities safely**: Please report security vulnerabilities via private repository advisories rather than public issues.
- **Meet the contributors**: Visit our [Contributors Wall](https://makitdev.com/contributors.html) to see everyone shaping the organization.
